# Medication Management App

## 📱 Overview
A mobile application designed to help users manage and track their medications in an organized and user-friendly way.

## 🎯 Project Objective
The project aims to provide users with a simple way to record medication information and manage their medication schedules.

## ✨ Key Features
- Add and manage medications
- Specify dosage and frequency
- Add notes for each medication
- Simple and user-friendly interface
- Organized medication information

## 🛠️ Technologies
- Flutter
- Dart
- BLoC State Management
- Material Design

This project was developed as part of my academic work in Information Systems, applying system analysis, application design, and mobile application development concepts.
